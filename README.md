# Profile Canvas Interface 🎨✨

![Profile Canvas Interface Preview](https://raw.githubusercontent.com/frontenddeveloper2025dev/Content-Hub/refs/heads/main/Content%20Hub.png)

## Overview

**Profile Canvas Interface** is a modern frontend interface built with **React, TypeScript, and Vite**.  
The project focuses on creating a clean and responsive user experience using modern UI practices, reusable components, and utility-first styling.

The application was developed as part of frontend practice, experimentation, and UI exploration using contemporary React workflows and component-based architecture.

---

# 🚀 Tech Stack

- React 18.2.0
- TypeScript 5.7.2
- Vite 6.3.1
- Tailwind CSS 3.4.1
- shadcn/ui
- React Router 7.5.1

---

# ✨ Features

- Responsive interface
- Modern React architecture
- Reusable UI components
- Type-safe development with TypeScript
- Fast development environment using Vite
- Tailwind CSS utility-first styling
- Pre-configured shadcn/ui components

---

# ⚡ Quick Start

## Install dependencies

### Using bun (recommended)

```bash
bun install
```

### Using npm

```bash
npm install
```

---

## Start development server

### Using bun

```bash
bun dev
```

### Using npm

```bash
npm run dev
```

---

## Build for production

### Using bun

```bash
bun run build
```

### Using npm

```bash
npm run build
```
